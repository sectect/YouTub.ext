A minimal browser extension for automatic YouTube intro and outro skipping and nonstop playback.

- Skip 5, 10, 30, or 60 seconds, or choose a custom duration.
- Automatically confirm the "Continue watching?" prompt.
- Save preferences and follow your system's light or dark theme.

## Quick start

Requires Node.js 22 or newer.

```sh
npm install
npm run build
```

Open `chrome://extensions` or `edge://extensions`, enable **Developer mode**, select **Load unpacked**, and choose `dist/youtub-ext-v1.0.0/`. Refresh YouTube after installing.
